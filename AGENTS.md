## Project Overview

Deziner is a VS Code design-as-code solution built to bridge the gap between design and development.

Instead of storing designs in a closed visual format, Deziner keeps design files as readable, structured code. Developers/Agents can create and edit design files, define reusable components, and manage design tokens while keeping everything close to real project code.

Components in Deziner are defined as custom web components, and design tokens are stored as CSS variables. This makes the design system easier to understand, reuse, modify, and integrate into actual applications.

Designing can be done in two ways: visually through the Deziner VS Code extension UI, or programmatically through AI agent prompts. Because the design files are code-based, AI agents can read, understand, and modify them more reliably.

Another important feature of Deziner is that AI agents can convert designs into actual project code with minimal friction. Because Deziner stores designs as code, and structures them closely to the final code used in real projects, agents can understand the design more easily and translate it into production components with less overhead.
